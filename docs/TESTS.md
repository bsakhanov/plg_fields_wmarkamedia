Среда: Ubuntu 24.04, PHP 8.3.6, MariaDB 10.11.14, чистые установки **Joomla 6.2.0** и **Joomla 5.4.9** через `installation/joomla.php`, встроенный сервер PHP, Chromium без окна (puppeteer-core). Дата проверок — 23 октября 2026 года. Прежние плагины проверялись на тех же установках.

## Что не проверялось

- Обновление кнопкой в админке и сверка sha256 (в `updates.xml` её нет); интеграционная проверка на Joomla 5 и на PHP 8.1, 8.2, 8.4 (CI гоняет только проверки без Joomla);
- Joomla 5.2–5.3, 6.0–6.1; создание копий при GD без WebP, при папке кэша без права записи, при одновременных запросах и для снимков крупнее 36 млн пикселей; PHP 8.1, 8.2, 8.4; PostgreSQL; Apache и Nginx (проверка шла на встроенном сервере PHP).
- Настоящие встраивания чужих сервисов (YouTube, TikTok, Instagram, Telegram, Facebook, VK, Rutube, Vimeo): адреса проверены, сами ролики — нет; тестовая установка без доступа к внешним сервисам.
- Сохранение формы кнопкой в админке из браузера (проверено сохранение через модель статьи и отображение формы).
- Строки ru-RU и kk-KZ на сайте с установленными языковыми пакетами (проверены разбор и полнота; казахский текст стоит показать носителю).
- Работа с реальной базой крупного сайта; чтение страницы читателем в Safari и Firefox.
- Поведение при тысячах значений и на нагруженном сайте.
